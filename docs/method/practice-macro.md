# 大量答题才能宏观把握

**问题：**

我明天白天全真模拟，但是我一想到新题没见过就焦虑，思考的时间也思考不了，真到了那个环境大脑一片空白，不提前看题准备，完全不知道该咋说？

---

**回答：**

如果你接触的题目比较少，你对一个类型的题目没有概念，那就会导致你见到很多的题都觉得它是新题，或者看到新的题目就有点慌。

如果你答的题多，见的题目多，那么你在脑海中就会建立起一个类型题目基本的答题思路框架和思路。这个时候，你见到题目就不会觉得它特别的新了，会觉得他似曾相识。

总之，你需要大量的去练习，通过接触大量的题目，才能够从更宏观的角度去思考问题。

# 答题观点要明确

> 答题的核心观点不要和稀泥，核心观点要明确、犀利。但是答完核心观点之后又要找补一下，体现出周全。

**题目示例：**

小张在值夜班，收到下属单位发过来的紧急报告，发现其中有文字和语法错误，现在有三种方式：第一种是直接提交给领导。第二种是在上面修改之后再提交给领导。第三种是将疑问反馈给下属，让下属修改之后再提交。请选择其中一种方式，谈谈你的看法。

*2024年4月29日河南省考面试题（市级以上）*

---

最近有同学在问这道真题，不算难，普遍的答法是分类讨论，这是没错的。但是在考场上我不太喜欢用分类讨论，因为观点不够鲜明，个性不强，不容易出彩。

题目要让你选择一种，建议只选一种。总的原则是**要解释清楚为什么要选择这一种，同时要说明这个选择它的缺点在哪里？自己在做完之后如何弥补这个缺点？**

比如说你选择第一种，那你就可以解释，说这个情况非常紧急，在夜间呈上来报告，同时还有一些文字错误，说明情况非常紧急，那必须先把这个情况给领导报告，之后我们再对其中的文字性错误进行修改。报告完之后你再说要赶紧跟下属单位进一步的核实情况，看看有什么是否有错漏的，然后及时将修改过后的材料再呈报给领导。

你也可以选第二种或第三种，就是不马上呈上去，那你就可以解释说我这个是为了避免产生误解，那你就要说我在修改的同时要及时的把核心的信息传递上去，避免延误时间。

**总之，你选一个，但是，你要把其他的缺点考虑到，在你选择这个选择的同时去做一些其他的事情，弥补它的这个缺陷。**

答题的核心观点不要和稀泥，核心观点要明确、犀利。但是答完核心观点之后又要找补一下，体现出周全。
