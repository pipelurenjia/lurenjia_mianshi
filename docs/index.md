## 核心方法论

### 1. 布点法 — 快速破题

一道题目上手，先找逻辑主线，在主线上布2-3个要点，每个要点再展开成2-3个小点。

**示例**：组织社区敬老活动
```
主线：了解情况 → 具体组织 → 后续优化
要点：年龄结构、分布、身体状况 → 文化活动、上门慰问 → 定期回访、加强宣传
```

### 2. 观点展开法 — 丰富内容

- **广度拓展**：把一个观点拆成多个组成部分
- **深度挖掘**：追问"为什么"和"怎么办"

### 3. 问答笔记法 — 高效积累

阅读时提炼问题和要点，复习时遮住答案复述。形成输入-输出闭环。

### 4. 复述法 — 告别背诵

看完材料，合上书，用自己的话讲出来。能讲出来才是真掌握。

## 核心理念

### 我们相信

1. **面试是练出来的，不是听出来的**
   
   听课只能让你知道"好答案是什么样"，真正能答出来，需要大量练习。

2. **思路比内容更重要**
   
   掌握了思考方法，遇到任何题目都能展开。死记硬背，换个题就不会了。

3. **要形成自己的框架**
   
   每个人都有自己的思维方式，找到适合自己的答题逻辑，比套模板更有效。

4. **真诚比技巧更重要**
   
   考官听了无数遍套路，真实的想法、接地气的表达，反而更能打动人。

### 我们不相信

- ❌ 背模板就能拿高分
- ❌ 金句开头的答案更出彩
- ❌ 听完课就能学会面试
- ❌ 必须报班才能上岸
