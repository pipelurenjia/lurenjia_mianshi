# 2026-10-20

## 首屏加载优化（19:55）

用户反馈首次打开会在「加载中...」停留几秒。

**实测（欧洲出口，仅看结构不看绝对值）**：
- 传输体积很小：HTML 9.1KB(br)、docsify.js 48.4KB(br)、vue.css 3.5KB(br)、README.md 4.1KB(br)、_sidebar.md 1.2KB(br)，合计约 66KB。**不是文件大，而是串行往返多**。
- 关键路径 4 趟：HTML → vue.css（`<link>` 在 head 尾部，阻塞渲染）→ docsify.js（body 末尾）→ md 文件 → Vue 渲染。
- **额外阻塞点**：百度统计 hm.js 原来是同步 `<script>`，排在 docsify.js 之后；而 docsify.js 内有 `DOMContentLoaded` 逻辑才启动，所以 hm.js 慢会直接推迟首屏。
- docsify 内部会分别拉 `_coverpage.md`、`_sidebar.md`、`README.md`。

**已改（`index.html`）**：
1. `assets/vue.css` 改为**内联**（删除 `<link>`，样式并入 `<style>`），省掉一次阻塞渲染的往返。
2. head 加 `<link rel="preload" as="script" href="/assets/docsify.js">`，让 JS 与样式并行下载。
3. 百度统计 `hm.js` 改为 `async`（`var _hmt = _hmt || []` 占位脚本保持同步，队列仍生效）。
4. `#app` 里的「加载中...」换成品牌化骨架：`.lrj-boot`（旋转环 + 站点名 + 正在加载内容），样式写在第一个 `<style>` 块内，避免裸文字像卡死。

**校验**：两个 style 块花括号平衡、`.markdown-section/.sidebar/.cover/.lrj-hero` 等关键选择器均在、无残留 vue.css 外链、`window.$docsify` 配置完整、骨架与 preload 存在。无头浏览器在本沙箱被拦，无法截图实测。

**未做（待定）**：
- 静态首屏（把封面 HTML 直接写进 `#app`）可把首屏从 ~2s 降到 ~0，但与 docsify 渲染衔接易闪烁，需谨慎。
- `_headers` 给 `.md` 加短缓存 + prefetch 才能真正省一次往返（当前 md 是 `max-age=0, must-revalidate`，prefetch 会被重新校验，白做）。
- 根本方案：Cloudflare 在中国大陆无节点，要显著提速需 ICP 备案 + 国内 CDN/对象存储，或迁到预渲染的静态站。

**环境**：本会话 agent-browser 已不存在（node 版本目录改为 `22.22.2-6`），Chrome/Edge headless 均被沙箱拦截，无法截图；本地预览仍需用多线程 HTTPServer（端口 3000）。
