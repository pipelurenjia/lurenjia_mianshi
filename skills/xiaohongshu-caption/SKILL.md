# 小红书正文写作

为长图/图片形式发布的内容，生成配套的正文文案。

---

## 核心原则

**正文 ≠ 图片文字重复**

正文的作用是：
1. **吸引点击** - 用痛点或好奇快速抓住注意力
2. **提炼框架** - 让不点开图的人也能get核心要点
3. **引导互动** - 提高评论率、收藏率
4. **标签引流** - 精准触达目标受众

---

## 正文结构

### 1. 开头（痛点/好奇）
- 2-3行，直击读者痛点
- 用口语化表达，可加emoji
- 例：「很多同学都有这个困惑：」「说真的，这个问题困扰了我很久」

### 2. 桥梁（引导看图）
- 1句话，说明长图价值
- 例：「今天分享一个方法，帮你xxx」「👉 长图详细展开，建议收藏」

### 3. 框架提炼（可选）
- 用列表或符号提炼核心要点
- 控制在3-5条
- 方便读者快速判断内容是否相关

### 4. 互动引导
- 1句话，引导评论或行动
- 例：「你现在最大的困惑是什么？评论区说说」「收藏起来慢慢看」

### 5. 标签
- 3-5个精准标签
- 覆盖核心受众可能搜索的关键词

---

## 字数控制

- 总字数：200-400字
- 开头：50字以内
- 框架提炼：100字以内
- 互动+标签：50字以内

---

## 常用模板

### 模板A：痛点引入型
```
很多[目标用户]都有这个困扰：[痛点]

[一句话解决方案]

👉 长图详细展开，建议收藏

📌 核心要点：[3-5条]

[互动引导]

#标签1 #标签2 #标签3
```

### 模板B：干货直给型
```
[核心结论]

[一句话解释]

✅ 具体步骤：[3-5条]

💡 关键点：[1句话]

收藏起来慢慢看👆

#标签1 #标签2 #标签3
```

### 模板C：对比反差型
```
以前我觉得[错误认知]
后来才发现[正确认知]

详细分析看长图👉

你有过类似经历吗？评论区聊聊👇

#标签1 #标签2 #标签3
```

---

## 注意事项

1. 不复制图片中的大段文字
2. emoji适度，不超过5个
3. 开头真诚，避免标题党
4. 标签精准，不堆砌无关热词
5. 语气口语化，像和朋友聊天
