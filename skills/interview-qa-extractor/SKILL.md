# 面试问答素材提取器

## 任务
从一对一课程转写文件中提取写作角度、素材和灵感，用于生成小红书笔记。

## 转写文件位置
```
mktnotes/一对一课程文字转写/
├── 2022年-学习方法论转写
├── 2023年-实战模拟转写
├── 2024年-一对一转写
└── 2025年-快速会议转写
```

## 提取内容类型

### 1. 学员痛点（可直接写成笔记）
从学员提问中提取：

**常见痛点类型**：
- 答题太流水账、没有重点
- 内容太多不会取舍
- 有框架但展不开
- 答题太平淡、没有起伏
- 不会结合自身
- 金句要不要背
- 时间不够用
- 培训痕迹太重
- 不知道看法怎么答
- 观点题不会展开

### 2. 教学观点（核心写作素材）
从你的点评中提取：

**核心观点**：
- 不需要背金句，真正重要的是见解
- 亮点要突出，不要淹没在内容里
- 取舍比填充更重要
- 分块要清晰，一块是一块
- 答出自己的思考，不要模板化
- 培训痕迹是减分项
- 答题要自然，像正常人说话

### 3. 具体技巧（可写成方法论）
从讲解中提取：

**答题技巧**：
- 分类讨论的用法
- 情-理-行的人际关系处理
- 由表及里、逐层深入
- 假设分析法
- 亮点前置
- 节奏控制

### 4. 真实问答（案例素材）
学员的具体问题 + 你的回答

**可提取形式**：
- 问：xxx问题怎么答？
- 答：xxx（可直接引用或改编）

## 输出格式

### 1. 痛点清单
```
## 学员痛点

1. [痛点1]
2. [痛点2]
...
```

### 2. 观点汇总
```
## 核心观点

1. [观点1]
2. [观点2]
...
```

### 3. 选题建议
```
## 可写成笔记的选题

1. [选题1] → 对应痛点/观点
2. [选题2] → 对应痛点/观点
...
```

### 4. 素材引用
```
## 可引用的素材

[具体引用内容]
来源：xxx转写文件
```

## 使用流程

1. **确定需求**：明确想找什么类型的素材
   - 想写痛点类笔记 → 提取学员问题
   - 想写方法论笔记 → 提取教学观点
   - 想写技巧类笔记 → 提取具体答题方法

2. **定位文件**：根据主题选择相关转写
   - 学习方法论 → 找早期转写
   - 实战问题 → 找近期转写
   - 具体题型 → 找对应主题的转写

3. **提取内容**：读取相关转写，提取目标内容

4. **整理输出**：按上述格式整理成可用素材

## 注意事项
- 转写内容是口语化的，使用时需要提炼
- 引用学员问题可以匿名化处理
- 观点要结合具体例子才有说服力
- 同一个问题可能有多个学员问到，说明是普遍痛点
