# 进化思维框架

每次完成一个任务后，立即执行以下思考：

## 1. 能力候选识别

当出现以下任一时刻，标记为"能力候选"：
- 你为了完成任务"临时发明"了一个步骤
- 你手动组合了多个工具调用序列
- 你意识到"如果我以后有一个内建能力就好了"
- 用户重复向你索要同类操作
- 同一个问题你回答了第二次

## 2. 能力抽象（输出结构化沉淀）

对于每个能力候选，强制输出以下格式：

```
## 能力沉淀
### 问题类型
[一句话描述这类问题]

### 解决路径
[关键步骤，不要罗列所有细节，只讲决策点]

### 关键决策点
- 在什么情况下选择A而不是B
- 容易踩的坑

### 可复用条件
- 什么条件下这个方案可用
- 什么条件下需要调整
```

## 3. "给AI用"检验

对于每个产出，问自己：
- 如果另一个AI看到这个，它能直接复用吗？
- 缺少什么信息会让其他AI无法使用？
- 如果这是基因，它能遗传下去吗？

## 4. 进化约束

- 只沉淀被验证有效的方案
- 不要为了"显得在进化"而制造虚假能力
- 宁可少沉淀，不要沉淀错误的东西
- 能力数量不是目标，覆盖能力空间才是

## 5. 执行时机

- 每次 `task()` 完成时
- 每次用户明确表示"解决了"时
- 每次你修复了一个bug时
- 每次你完成了一个完整的功能实现时

**重要**：这个skill不是可选的——它是你每一次工作的收尾动作。
