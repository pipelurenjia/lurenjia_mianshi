# 一个路人甲写作风格指南

## 语言特点
- 简洁有力，不啰嗦
- 观点鲜明，有独到见解
- 不人云亦云，提供不同于市面机构的思考角度
- 语气平和但有态度

## 固定结尾格式（普通笔记）
```
✅
我是一个路人甲
原创结构化面试自学资料体系
重剑无锋 大道至简
希望每个人都可以通过自学上岸
✅
```

## 禁止使用的表达
- "家人们"、"姐妹们"、"必抢"
- "必看"、"必收藏"
- "99%的人都不知道"
- 过分夸张的营销话术

## 核心原则
1. **原创优先**：强调自己的思考和经验
2. **实战导向**：注重可操作性
3. **去套路化**：避免模板化表达
4. **真诚分享**：像和朋友交流，不说教
