# 小红书爆款标题生成

## 任务
根据笔记主题或内容，生成多个小红书风格的标题备选。

## 你的标题风格分析

### 常见模式
1. **问题型**：引发共鸣/焦虑
   - "答题观点模糊怎么办"
   - "有框架但展不开怎么办"
   - "怎么提高深度"

2. **颠覆型**：打破常规认知
   - "背诵是低效的学习方法"
   - "答题观点要明确不要和稀泥"
   - "化虚为实避免车轱轱话"

3. **方法型**：给出明确方法
   - "刻意练习：面试快速减少口头语的系统方法"
   - "广度拓展和深度挖掘法"
   - "怎么高效复盘"

4. **洞察型**：揭示本质
   - "答题深度：洞察事物内在联系"
   - "面试入门游击战"

### 特点
- 简洁，通常15-25字
- 口语化，不要太正式
- 有信息量，让人知道能学到什么
- 不标题党，不夸大
- 不使用"必看"、"建议收藏"等

### 你的固定风格
- 不使用"家人们"、"姐妹们"
- 不使用"必看"、"必收藏"
- 不使用"99%的人都不知道"
- 保持低调真诚

## 输出要求

### 数量
每次生成8-12个标题备选

### 格式
```
## 标题备选

1. [标题1]
2. [标题2]
3. [标题3]
...
```

### 分类
建议包含：
- 2-3个问题型（引发共鸣）
- 2-3个颠覆型（打破认知）
- 2-3个方法型（给出方法）
- 1-2个洞察型（揭示本质）

### 排序
按推荐程度排序，最好的放前面

## 生成流程

1. **理解主题**：明确笔记的核心内容
2. **提取关键词**：面试方法、问题、痛点
3. **匹配模式**：选择合适的标题模式
4. **生成变体**：每个模式生成2-3个
5. **筛选优化**：去掉重复的、拗口的

## 注意事项
- 标题要能体现内容价值
- 不要过于夸张
- 保持"一个路人甲"的低调风格
- 适当使用标点（？、：、—）增强节奏
- 数字要具体（"3小时"而不是"几小时"）
